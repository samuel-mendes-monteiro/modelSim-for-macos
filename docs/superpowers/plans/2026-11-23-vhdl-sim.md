# VHDL Sim for macOS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Electron app that edits, compiles (GHDL) and simulates VHDL and shows VCD waveforms.
**Architecture:** Electron main process owns filesystem + GHDL subprocesses, exposed via a typed preload bridge (`window.api`). React renderer: project tree, Monaco editor, transcript, Canvas waveform.
**Tech Stack:** Electron, Vite (electron-vite), React 18, TypeScript, Monaco, Vitest.
**Spec:** docs/superpowers/specs/2026-11-23-vhdl-sim-design.md

## Global Constraints
- macOS arm64; GHDL from Homebrew (LLVM backend), found via PATH or `/opt/homebrew/bin/ghdl`.
- Build artifacts in `<project>/.vhdlsim/` (never pollute sources).
- Default `--std=08`, selectable `93c`.

## Review Focus
- GHDL missing → Transcript shows install hint (`brew install ghdl`), app does not crash. (Task 2 test)
- Files in wrong order (tb before design) → still compiles via retry loop. (Task 2 test)
- VCD with multi-bit vectors containing `x`/`z`/`u` → shown as X/Z, radix conversion doesn't throw. (Task 1 test)
- `run all` on a testbench that never stops → enforced timeout + kill, message in transcript. (Task 2)
- Error lines with spaces in the project path → diagnostics parsing still resolves file + line. (Task 2 test)

### Task 1: VCD parser + radix formatting
**Files:** `src/lib/vcd.ts`, `src/lib/radix.ts`, `tests/vcd.test.ts`, `tests/radix.test.ts`
**Produces:** `parseVcd(text: string): VcdData` where `VcdData = { timescaleFs: number; endTime: number; signals: VcdSignal[] }`, `VcdSignal = { id; name; scope: string[]; width; changes: {t:number; v:string}[] }`; `formatValue(bits: string, radix: 'bin'|'hex'|'unsigned'|'signed'): string`.
- [ ] Tests: scopes/names parsed; scalar + vector changes; shared id codes map to both signals; `formatValue('1010','hex')==='A'`, `('1111','signed')==='-1'`, `('1x10','hex')==='X'`.
- [ ] Implement, run `npx vitest run`, commit.

### Task 2: GHDL runner (main process)
**Files:** `electron/ghdl.ts`, `tests/ghdl.test.ts`
**Produces:** `parseDiagnostics(out: string): Diagnostic[]` (`{file,line,col,severity,message}`), `scanUnits(src): {entities: {name, hasPorts}[]}`, `compileProject(dir, files, std, log): Promise<{ok, diagnostics}>`, `simulate(dir, top, stopTime|'all', std, log): Promise<{ok, vcdPath?}>`.
- [ ] Tests: diagnostics with spaces in path; entity without ports detected as testbench.
- [ ] Integration (skipped if no ghdl): sample counter + tb compiles in reversed order and produces a VCD.
- [ ] Commit.

### Task 3: Electron shell + IPC
**Files:** `electron/main.ts`, `electron/preload.ts`, `src/types/api.d.ts`, config files.
- IPC: `openFolder`, `listFiles`, `readFile`, `writeFile`, `compile`, `simulate`, `readVcd`, `openVcdFile`, streaming `log` events.

### Task 4: UI
**Files:** `src/App.tsx`, `src/components/{ProjectPanel,EditorPane,Transcript,Waveform}.tsx`, `src/lib/vhdlLanguage.ts`, `src/styles.css`.
- Toolbar: Open Folder, Save, Compile All, top entity select, run time input, Run / Run All.

- Waveform: signal list w/ radix context menu, zoom in/out/fit (buttons + Cmd+wheel), click = cursor 1, shift-click = cursor 2, delta shown.
